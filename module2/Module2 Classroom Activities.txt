 ACTIVITY 2:

INTERACTIVE FORM DEVELOPMENT


QUESTION: Create a registration form with validation and user feedback
mechanisms.

ANSWER:

File name: activity2.html

CODE:

<!DOCTYPE html>
Registration Form
    <h1>Registration Form</h1>

    <form id="registrationForm">

        <label>Name:</label>
        <input type="text" id="name">
        <br><br>

        <label>Email:</label>
        <input type="email" id="email">
        <br><br>

        <label>Password:</label>
        <input type="password" id="password">
        <br><br>

        <input type="submit" value="Register">

    </form>

    <p id="message"></p>

    <script>
        document.getElementById("registrationForm").addEventListener("submit", function(event) {

            event.preventDefault();

            var name = document.getElementById("name").value;
            var email = document.getElementById("email").value;
            var password = document.getElementById("password").value;
            var message = document.getElementById("message");

            if (name == "" || email == "" || password == "") {
                message.innerHTML = "Please fill all the fields.";
            }
            else if (password.length < 6) {
                message.innerHTML = "Password must contain at least 6 characters.";
            }
            else {
                message.innerHTML = "Registration successful!";
            }

        });
    </script>

RESULT: The form checks whether all fields are filled. It also checks
the password length and displays a feedback message to the user.

ACTIVITY 3:

DOM MANIPULATION WORKSHOP

QUESTION: Dynamically update webpage content based on user actions such
as clicks and form submissions.

ANSWER:

File name: activity3.html

CODE:

<!DOCTYPE html>
DOM Manipulation
    <h1>DOM Manipulation Example</h1>

    <p id="text">This is the original text.</p>

    <button onclick="changeText()">Click Me</button>

    <script>
        function changeText() {
            document.getElementById("text").innerHTML =
                "The text has been changed using JavaScript.";
        }
    </script>

RESULT: When the user clicks the button, JavaScript uses DOM
manipulation to change the webpage content.
